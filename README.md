# PeerLearn
version control and collaborative development agile
Resource Request Feature
Overview

The Resource Request feature allows students to post requests for learning resources on a specific topic. Other students can view these requests and recommend suitable resources.

User Story

As a student, I want to post a request for learning resources on a specific topic so that peers can recommend suitable resources.

Main Features
Create a learning resource request.
Enter the topic or subject.
Select the required resource type.
Add a description of the required material.
Submit the request.
Allow peers to view the request and recommend resources.
Resource Types

The request can be made for:

Notes
PPTs
Videos
Language materials
Other learning resources
Expected Outcome

Students can clearly communicate what learning material they need, allowing their peers to provide relevant and useful recommendations.
